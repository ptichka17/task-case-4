## Описание
Репозиторий содержит решение кейс-задачи №4:

Вычисление максимальной силы драконьей стаи при заданном общем количестве голов N (0 < N < 100). Сила стаи определяется как произведение количества голов каждого дракона, где каждый дракон может иметь не более 7 голов.

Задача сводится к оптимизации: распределить N голов между драконами так, чтобы произведение было максимальным. Используется алгоритм на основе разбиения на числа, близкие к 3 (оптимально для максимизации произведения), с обработкой особых случаев для малых N.

## Математическая модель
Максимизация произведения k1, k2, … , ka где ki = N, 1 ≤ ki ≤ 7 для всех i и a – количество драконов.  Алгоритм предпочитает разбиение на 3, с корректировкой остатков (2 или 4), чтобы избежать неэффективных 1.

## Алгоритм решения
- **Основной подход**: жадный алгоритм.

## Тестирование и верификация

Протестировано на примерах для малых и больших N (до 99).
Краевые случаи: N=1 (1), N=4 (4), N=99 (максимальное с разбиением на 3, 2, 4).
Алгоритм соответствует математической оптимальности для данного ограничения.

## Общие характеристики
Алгоритм прост, эффективен и универсален для N < 100.
